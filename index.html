Research

Sample-efficient interatomic potentials

Multitask learning with semiempirical orbital charges as an auxiliary target makes equivariant machine learning interatomic potentials more data-efficient.

NeurIPS 2026 Sim2Science and ML4Molecules Paper

Active learning for closed-loop discovery

Inference Set Design is an active learning strategy that targets the hardest examples in a screening library. It reduces the cost of high-throughput molecular screens by up to 60%.

ICLR 2025 USPTO patent application Paper Code Patent

Electronic fingerprints for materials space

ProDosNet is a graph neural network that generates orbital-resolved densities of states. Its electronic fingerprints map the entire Materials Project, so new materials can be found near known high performers.

PRX Intelligence 2026 Paper Code Demo

Foundation models for OLED emitter discovery

A virtual screening pipeline built on chemical foundation models that achieves <100 meV error on experimental emission energies and capable of screening ~1 million organometallic molecules per day on 8 GPUs.

Preprint 2026 Paper

Modelling protein–organometallic ligand interactions with MLIP

A pipeline that combines OpenFold-3 co-folding, AutoDock Vina, GROMACS, and the UMA atomistic foundation model to run molecular dynamics simulations of protein bound to organometallic ligands.
